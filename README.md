# Exam Ticket Generator 🎓

Консольное приложение на C# (.NET) для автоматизации генерации экзаменационных билетов. Приложение запрашивает данные студента, генерирует случайный номер билета и надежно сохраняет результаты в локальный Excel-файл.

## Особенности
- **Мгновенное сохранение:** Данные пишутся в Excel сразу после генерации билета. Приложение устойчиво к сбоям по питанию.
- **Безопасное завершение:** Выход из режима ожидания осуществляется по нажатию клавиши `ESC`.
- **Защита от блокировок файла:** Если `journal.xlsx` открыт пользователем в Excel, приложение не падает, а перехватывает `IOException` и просит закрыть файл.
- **Строгая валидация:** Защита от пустых строк и случайных нажатий `Enter` или `Backspace`.

## Требования
- .NET 6.0 или новее
- Библиотека `ClosedXML` для работы с форматом `.xlsx`
